# m4a-web

GBA の ROM から MP2K (m4a, いわゆる Sappy) のサウンドドライバを探し、曲を再生するブラウザのツールです。ROM はブラウザの中だけで読み、どこにも送りません。

## 使い方

- ROM ファイルを選ぶか、ウィンドウにドロップします。
- 開いた ROM はブラウザの中 (IndexedDB) に保存し、左のライブラリから開き直せます。同じ ROM はファイル名が違っても 1 つにまとめます (中身の SHA-1 で見分けます)。`?rom=` で開いたものは保存しません。
- 曲の一覧の行をダブルクリックするか、番号のところの ▶ を押すと鳴らします。一覧の長さは、開いたあとに少しずつ測って埋めます。
- 下の再生バーで、前・次の曲、シャッフル、繰り返し (1 曲を繰り返す → なし → 全曲を繰り返す) を切り替えます。既定は 1 曲を繰り返します (同じ曲テーブルに効果音やボイスも並んでいるので、続けて流すと BGM の合間に短い音が挟まるため)。
- 右の「再生中」には、スペクトラムと、トラックごとの音量・鳴っている鍵盤を出します。再生バーの右のボタンで出し入れします。
- 曲テーブルの位置・ミキサー・同時発音数・ループ回数は、見出しの ⚙ で変えられます。曲テーブルの位置は ROM から自動で探しますが、見つからないときや違う場所を見たいときはアドレスを入れてください (`0x0825E56C` のような GBA のアドレスでも、`25E56C` のような ROM の中の位置でもかまいません)。
- 曲ごとの「…」から、曲ヘッダの情報を見たり WAV で保存したりできます。
- OS のメディアキーやロック画面の操作 (Media Session API) にも対応しています。
- 今の曲は URL の `#番号` に入ります。`?rom=<URL>` で ROM の場所を渡すと、ドロップしなくてもその ROM を開きます (相対パスはページの場所から。別のサーバから読むときは、そのサーバが CORS のヘッダを返す必要があります)。

### キーボード

| キー                      | 操作                                                 |
| ------------------------- | ---------------------------------------------------- |
| Space                     | 再生・一時停止                                       |
| ← / →                     | 5 秒戻る・進む                                       |
| P / N (Shift+← / Shift+→) | 前の曲・次の曲 (3 秒より後で P を押すと曲の頭に戻る) |
| ↑ / ↓                     | 音量                                                 |
| M                         | 消音                                                 |
| R                         | 繰り返しを切り替える                                 |
| S                         | シャッフル                                           |

## 曲テーブルの探し方

`m4a/detect.ts` で、次の順に探します。

1. `m4aSongNumStart` の機械語 (先頭 0x1E バイト) を ROM から探します。ライブラリを組み直したゲームでは命令が少し違うので、2 通りの並びを見ます。
2. その関数のリテラルプールにある `gSongTable` のアドレスを読み、曲ヘッダへのポインタが並んでいるかを確かめます。
3. 少し手前にある `m4aSoundInit` のリテラルプールから、`m4aSoundMode` に渡す値 (同時発音数、音量、ミキサーの周波数、DAC のビット数、リバーブ)、MusicPlayer の数、`gMPlayTable` を読みます。`gSongTable` は `gMPlayTable` のすぐ後ろに置かれるので、辻褄が合う並びを選びます。

ライブラリをそのまま使っていないゲーム (自前のドライバや改造したもの) では見つかりません。

## できないこと

- 圧縮されたサンプル (BDPCM) と、黄金の太陽のシンセ音色には対応していません。それらを使う曲は正しく鳴りません。
- 実機のミキサー (ミキサーの周波数で混ぜて 8 ビットに落とすこと) は再現しておらず、44100 Hz・浮動小数点で混ぜます。そのため実機より澄んだ音になり、ミキサーの周波数が低いゲームほど違いが大きくなります。
- リバーブは実機 (`SoundMainRAM`) と同じ仕組み (数フレーム前の出力を混ぜ直す) で掛けますが、8 ビットでの丸めはしていません。実機と同じく、CGB の音には掛けません。

## m4a/

曲を PCM に書き出すモジュールです。[bokmagic-web](https://github.com/akatsuki105/bokmagic-web) の `m4a/` を持ってきて、曲テーブルの検出 (`detect.ts`)、音を作らずに曲の長さを測る `measureSong`、トラックごとに鳴っている音の記録 (`renderSong` の `trace`) を足しました。ディレクトリの外のファイルを import しないので、ほかのツールにもそのまま持っていけます。使い方は `m4a/mod.ts` の先頭のコメントを参照してください。
