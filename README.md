# m4a-web

GBA の ROM から MP2K (m4a, いわゆる Sappy) のサウンドドライバを探し、曲を再生するブラウザのツールです。ROM はブラウザの中だけで読み、どこにも送りません。

## 使い方

- ROM ファイルを選ぶか、ウィンドウにドロップします。
- 曲テーブルの位置とミキサーの設定は ROM から自動で探します。見つからないときや違う場所を見たいときは、曲テーブルの欄にアドレスを入れてください (`0x0825E56C` のような GBA のアドレスでも、`25E56C` のような ROM の中の位置でもかまいません)。
- 選んでいる曲は URL の `#番号` に入ります。`?rom=<URL>` で ROM の場所を渡すと、ドロップしなくてもその ROM を開きます (相対パスはページの場所から。別のサーバから読むときは、そのサーバが CORS のヘッダを返す必要があります)。

## 曲テーブルの探し方

`m4a/detect.ts` で、次の順に探します。

1. `m4aSongNumStart` の機械語 (先頭 0x1E バイト) を ROM から探します。ライブラリを組み直したゲームでは命令が少し違うので、2 通りの並びを見ます。
2. その関数のリテラルプールにある `gSongTable` のアドレスを読み、曲ヘッダへのポインタが並んでいるかを確かめます。
3. 少し手前にある `m4aSoundInit` のリテラルプールから、`m4aSoundMode` に渡す値 (同時発音数、音量、ミキサーの周波数、DAC のビット数、リバーブ)、MusicPlayer の数、`gMPlayTable` を読みます。`gSongTable` は `gMPlayTable` のすぐ後ろに置かれるので、辻褄が合う並びを選びます。

ライブラリをそのまま使っていないゲーム (自前のドライバや改造したもの) では見つかりません。

## できないこと

- 圧縮されたサンプル (BDPCM) と、黄金の太陽のシンセ音色には対応していません。それらを使う曲は正しく鳴りません。
- 実機のミキサー (8 ビットの DAC、ミキサーの周波数での量子化) やリバーブは再現しておらず、それらしく鳴らす程度です。

## m4a/

曲を PCM に書き出すモジュールです。[bokmagic-web](https://github.com/akatsuki105/bokmagic-web) の `m4a/` を持ってきて、曲テーブルの検出 (`detect.ts`) を足しました。ディレクトリの外のファイルを import しないので、ほかのツールにもそのまま持っていけます。使い方は `m4a/mod.ts` の先頭のコメントを参照してください。

## 参考にしたもの

- [GBA Mus Ripper](https://github.com/berg8793/gba-mus-ripper) (Bregalad さん、CaptainSwag101 さん、berg8793 さん): 同梱の sappy_detector (検出の処理は loveemu さんによるもの) の、`m4aSongNumStart` の機械語から曲テーブルとドライバの設定を探す方法を参考にしました。コードは共有していません。
